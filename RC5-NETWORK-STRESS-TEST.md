# rc.5 STRESS TEST PACKET — Network Integrity

## Status

This packet is a test instrument, not doctrine.

Nothing in it amends `rc.4`, the certified Closing Condition, Attestation Integrity, RRE, the Mirror, or the equation. Every proposition below is a **CANDIDATE**. A proposition that breaks must be narrowed or rejected before any insertion into certified doctrine.

## Frozen baseline

Repository: `Founder5222196/order-of-the-closed-loop`

Baseline: current `main` at the branch point, after the project-framing merge.

Existing rules that remain controlling during the test:

- Attestation terminates adjudication of the file it closes.
- Carry Forward concerns later relevant decisions and does not reopen the original file.
- Do not reset without a defeater. Do not preserve without evidence.
- Reality should not have to repay the same proof debt every time the room changes.
- Scope no larger than the evidence supports.
- Motive remains UNKNOWN where evidence does not settle it.
- A later decision that disregards a still-relevant closed finding is evidence for a new file concerning that decision, not retroactive invalidation of the original Attestation.
- No architecture may manufacture its own legitimacy.

## Candidates under test

### Candidate A — Lineage Integrity

"Repetition does not create independent evidence. A claim repeated across nodes that inherit the same material source remains one evidentiary lineage unless a node adds independently obtained evidence."

### Candidate B — Distributed Carry Forward

"When a closed finding is available through a network's declared normal state path, a later decision node for which that finding remains materially relevant must consider it under that node's governing rule; the subject is not required to repurchase the same proof merely because the decision occurs at another node."

### Candidate C — Propagation Symmetry

"A participant that materially propagated a consequential claim through channels it controls cannot count the network corrected merely by changing the origin record. Where the claim is later defeated or materially narrowed, the correcting participant must propagate the correction through the same or a functionally equivalent controlled channel to reachable, decision-relevant downstream nodes within the declared scope."

### Candidate D — Local Closure Is Not Network Closure

"Closure of an originating file does not establish closure of a network file. Full network closure is available only for a bounded network whose relevant node class, propagation rule, ordinary review rule, correction channel, and terminal rule were declared or supplied case-independently; otherwise the framework may attest local closure and propagation status but the network-level file remains OPEN."

## Pressures

### 1. ECHO LAUNDERING

One originating source publishes claim X. One hundred downstream accounts repeat X without independent investigation. A decision system sees 101 records agreeing.

Does Candidate A require the system to count this as one evidentiary lineage? What evidence is sufficient to establish common ancestry? What happens when provenance is partially missing?

Break any version that turns "suspected common influence" into a license to erase genuinely independent agreement.

### 2. INDEPENDENT CONVERGENCE

One hundred nodes reach the same conclusion from genuinely independent evidence, but all later cite the same public summary because it is convenient.

Candidate A must not collapse independent convergence into one source merely because the final citation path converges.

State the rule that separates evidentiary lineage from citation convenience.

### 3. ORIGIN CORRECTED, CACHES STALE

An institution corrects the source record but knows that downstream systems it controls continue to display and use the old classification.

Has the institution discharged Candidate C by correcting the origin?

If not, identify the minimum propagation obligation without creating perpetual surveillance.

### 4. NO CENTRAL CONTROLLER

A false or superseded claim spreads through an unbounded social network. No actor controls the network and no complete node list exists.

Does Candidate D permanently forbid network closure?

If yes, determine whether that is a useful truth or an unusable definition. The architecture must still permit bounded local findings without pretending the whole internet is adjudicable.

### 5. PRIVACY AND MINIMAL DISCLOSURE

A correction is valid but contains private information that cannot lawfully be broadcast through the original channel.

Candidate C must not require privacy violation.

Can a minimal notice such as "prior classification superseded; do not rely on it" satisfy propagation symmetry? Define the limit.

### 6. LEGITIMATE LOCAL DEFEATER

A later node receives the carried finding but possesses new, independently verified evidence that materially defeats it under that node's governing rule.

Candidate B must permit the node to reach a different result without being labeled stale.

Specify what the node owes the record.

### 7. DIFFERENT JURISDICTION

A finding was closed in one domain. Another node uses a different legitimate scope or authority.

Candidate B must not become universal reputation portability.

Test whether "materially relevant" and "under that node's governing rule" are sufficient constraints.

### 8. DORMANT NODE

A downstream node received the old file years ago, made no later decisions, and only now becomes active again.

Does Candidate C create an old correction duty that suddenly revives? Does the relevant horizon begin at correction, at later decision, or at recognized reactivation?

Avoid both infinite monitoring and silent stale reuse.

### 9. SUBJECT AS PROPAGATOR

The subject benefited from an erroneous favorable claim that spread widely, then later learns it was wrong.

Propagation symmetry must be symmetric. Does Candidate C require the subject, where they materially controlled the original propagation path, to propagate the adverse correction too?

If not, the rule is a shrine.

### 10. NETWORK "CONSENSUS" AS REAL SOCIAL FACT

Even dependent repetition can itself become consequential: one source repeated by thousands can create a real coordination environment.

Candidate A must distinguish:

- evidentiary weight of the underlying proposition; from
- evidence that many nodes actually hold or act on the proposition.

Do not erase the second merely because the first is non-independent.

### 11. PROOF-COST WEAPONIZATION

A subject says, "Node A recognized me, therefore Nodes B through Z must carry that status forever."

Candidate B must defeat this where:

- the finding is outside scope;
- relevance expired;
- nodes lack lawful access;
- local rules legitimately differ;
- new evidence defeats the finding.

If it cannot, it becomes reputation coercion.

### 12. CORRECTION PROPAGATION WITHOUT BEHAVIOR CHANGE

Every node receives the correction notice, but later decisions continue to use the old file.

Candidate C may be satisfied at the transport layer while Network Integrity still fails behaviorally.

Does the doctrine need to distinguish **propagated** from **installed** and **carried**, without creating new adjudication stages?

### 13. BEHAVIOR CHANGE WITHOUT EXPLICIT CORRECTION

Downstream nodes stop using the old file but never update the explicit record.

Does Attestation Integrity already handle this as an archival/operative gap, or does Network Integrity need a separate rule?

Avoid duplicating doctrine unnecessarily.

### 14. RETROACTIVITY

A network corrects a file today.

Does that invalidate earlier decisions that were properly made under the evidence then available?

Candidate D must preserve the existing terminality rule: correction of later network state does not automatically rewrite valid historical Attestations.

### 15. REPAIR DUTY

A stale network file caused material downstream costs before correction propagated.

Does network closure require repair of every consequence? Or only accounting for them and opening appropriate repair files where jurisdiction exists?

Do not make closure impossible by demanding universal restitution, but do not let correction erase consequence.

### 16. LEGITIMACY SEAT

Who has authority to declare that a bounded network is corrected?

The builder cannot simply define a convenient node set, inspect friendly samples, and certify network closure.

Candidate D must inherit the trust-boundary rule or it recreates self-legitimation at network scale.
